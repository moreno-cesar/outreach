# Outreach

A simple relationship manager for staying in touch with key clients, managers, and vendors — built as a three-pane app (categories, contact list, profile).

## What it does (V1)
- Track each person's name, company, category, and the last time you spoke
- Flags anyone you haven't spoken with in 30+ days
- One-click "log a conversation today"
- Add people and categories on the fly; notes autosave
- Muted, Apple-inspired visual style

## What's not in yet
Email, LinkedIn, and Facebook integrations are intentionally left out of V1.

## Running it
`index.html` is a single self-contained page. Open it directly in a browser, or serve the folder with any static file server. Data persistence in this exported copy depends on the hosting environment — the original build runs on Claude's Artifact platform, which provides live, saved storage out of the box.
